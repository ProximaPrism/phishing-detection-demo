# BERT Preprocessing + Classifier Model Hybrid Demostration

This is the sister demostration app for [this project](https://github.com/ProximaPrism/phishing-detection-with-bert-preprocessing).

## Project Information

This project is an [IMAP-based web email client](/app) using `FastAPI` that integrates with the model 
for detecting phishing within the emails of the account supplied.

The demo is currently hosted **using Railway** on:

https://phishing-detection-demo-production.up.railway.app

## How to Login

This application uses the IMAP protocol for obtaining a user's emails using **app passwords**.

On Gmail and Outlook accounts, you **will** have to create an app password to be able to use the demo. 

Information on how to create app passwords for these accounts are listed below:
- [Gmail](https://support.google.com/accounts/answer/185833?hl=en)
- [Outlook](https://www.microcybersec.com/post/how-to-create-and-use-an-app-password-for-outlook)
